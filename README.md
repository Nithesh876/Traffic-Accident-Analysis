# 🚦 Traffic Accident Data Analysis (2020–2023)

This project analyzes road traffic accident data from 2020–2023 using Python.

It provides insights into:
- Yearly crash trends
- Death statistics
- District-wise accident analysis
- Correlation between crashes and deaths
- Visualizations

---

## 📊 Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn

---

## 📁 Dataset

The dataset contains district-wise road crashes and deaths from 2020–2023.

Columns include:

- District
- Road Crashes 2020–2023
- Deaths 2020–2023

---

## ▶️ How to Run

### 1 Install requirements

```
pip install -r requirements.txt
```

### 2 Run program

```
python traffic.py
```

---

## 📈 Output

The program generates:

- Line charts (Yearly trends)
- Bar charts (Top districts)
- Scatter plots (Correlation)
- Pie charts (Distribution)
